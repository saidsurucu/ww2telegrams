# WWII Turkish & Allied Archival Cipher Corpus (1939–1945) — `ww2telegrams.surucu.dev`

Bilingual (`TR` + `EN`) static academic edition of World War II (`1939–1945`) encrypted telegrams and cipher keys from the Turkish State Archives (`BCA`, `MSB ATASE`, `Dışişleri TDA`):

1. **`index.html` / `en/index.html`** — **1939 «YASA» 81-Cell Zero-Free Homophonic Cipher Key (`BCA 30-10-0-0, 65-435-9`) & `1877 → 1939` Ottoman–Republican Cryptographic Continuity** (with live 4-digit encryptor/decryptor and `1877 ↔ 1939` matrix comparator).
2. **`iskenderiye-1942.html` / `en/iskenderiye-1942.html`** — **1942 Alexandria (`MTCI`) Undeciphered 4-Digit Radio Cipher Intercepts (`MSB ATASE 110-9-1-14, 2-0-125`, No. 142 & No. 145)** & **1939 Berlin General Mittelberger Cipher (`1-0-63`)** (with live Modulo-10 additive pad cryptanalysis workbench).
3. **`meteoroloji-1940.html` / `en/meteoroloji-1940.html`** — **1940 `RAF` / Turkish Meteorological Service Sliding-Strip (`A..J`) Synoptic Cipher Machine (`BCA 30-10-0-0, 188-289-8`)** (with interactive 5-row orange sliding-strip simulator).
4. **`kulliyat-1939-1945.html` / `en/kulliyat-1939-1945.html`** — **1939–1945 Archival Cipher Corpus Inventory (`149` records across `BCA`, `ATASE`, and `TDA`)**.
